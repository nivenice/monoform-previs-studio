# MONOFORM · AGENT 版本更新记录

本文件按版本记录每次发布的内容。之后每次更新都遵循同一流程：

1. 在本文件顶部新增 `## v<版本> · <日期>` 小节，写清新增、改进、修复和兼容性变化。
2. 提升 `package.json` 的 `version`，并同步 `package-lock.json`。
3. 同步 `docs/version.json` 的 `version`、`releasedAt`、`notes` 和 `downloadUrl`，让应用内「关于 → 检查更新」能读到新版本。
4. 重新打包安装包，更新 `downloads/` 与 `downloads/SHA256SUMS.txt`，再更新 README 的下载链接。

`docs/version.json` 是应用内检查更新读取的唯一清单；`CHANGELOG.md` 是给人看的完整记录。两者内容应保持一致。

## v0.7.0 · 2026-11-26

### 新增

- 顶部栏新增「关于」按钮，打开关于面板后可查看产品说明、当前版本、运行平台和更新方式。
- 关于面板新增「检查更新」：读取项目仓库的 `docs/version.json`，按版本号比较当前版本与最新发布版本，并显示更新说明。
- 桌面版发现新版本后可直接「下载安装包」到系统下载目录，显示下载进度；下载完成后可打开安装包或打开所在文件夹。
- 关于面板提供更新日志、项目仓库和所有安装包的 HTTPS 链接，点击后由系统浏览器打开。
- 新增 `docs/CHANGELOG.md`（版本更新记录）和 `docs/version.json`（更新清单），确立“先记录更新内容、再提升版本号”的发版流程。

### 改进

- 渲染层版本号在构建时从 `package.json` 注入，桌面版同时通过 preload 读取安装包实际版本，避免界面版本与安装包不一致。
- 更新检查与下载都在 Electron 主进程完成：渲染层不直接访问外网，下载地址只允许 GitHub 可信域名，且只能下载刚刚检查到的那一个安装包。
- 没有网络、更新服务器不可达或清单格式异常时，检查更新会给出中文提示，不影响搭景、动画和导出。

### 兼容性

- 工程 schema 未变化，`PROJECT_VERSION` 仍为 16；升级后可直接打开旧工程。
- 0.6.0 及更早版本没有「关于」面板，需要手动下载安装一次 0.7.0；从 0.7.0 起可以直接在应用内检查更新。
- 浏览器版保留关于面板：显示当前构建版本和说明，并提示刷新页面即为最新版本。
- 版本号由 0.6.0 提升到 0.7.0；对应安装包为 `MONOFORM-0.7.0-win-x64-setup.exe`。

## v0.6.0 · 2026-08-05（历史基线）

0.6.0 是本次更新记录建立前的最后一个发布版本，安装包在 2026-11-26 前持续更新。该版本已包含：

- Electron 桌面版与 Windows 安装包，同时保留 GitHub Pages 浏览器版。
- 多镜头管理、人物骨骼与动作预设、参考图、光照、摄像机与人物双轨关键帧、PNG / MP4 / 工程 JSON 导出。
- 右侧「AI 助手」：流式对话、会话历史（SQLite）、对话/识图两套模型配置，以及把场景图转成可编辑白模的默认工具。
- 场景编辑工具与「骨骼动画师」子代理，可由自然语言完成镜头时长、机位与人物关键帧。
